Your first job

  1. Create a resource class and a token with the CircleCI CLI.
  2. Download the release, start Swarm, create the secrets, and deploy the stack. Follow Quickstart on Linux or Quickstart on Windows Server.
  3. Run a sample job twice, and see a new container each time. Then point a real workflow at your class: examples/ has a job config for every class.

Install paths, operations, and security are in the documentation.

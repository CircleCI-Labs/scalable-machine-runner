Documentation
Configure

Configure

  • Resource classes: Resource classes as Swarm services: default sizes and limits, how to add a class, replica counts, persistent classes, Rerun job with SSH, and the stack variable reference.
  • Images: Run the runner in stock Linux and Windows images with a read-only mount, and bring your own image.
  • Docker builds: Build container images from jobs with an opt-in service that mounts the host Docker engine, and compare the rootless and daemonless alternatives.
  • MicroVM jobs: Run each job in its own microVM with Kata Containers on labeled Linux nodes, set up the nodes, and learn what the add-on costs and what it does not cover.
  • Container mode: Run CircleCI Docker-executor jobs (docker - image and service containers) on Docker Swarm with no Kubernetes. A prototype agent, its architecture, security model, and limits.

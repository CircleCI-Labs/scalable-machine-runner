# The sidebar of the docs site: its order, its groups and the labels of its pages (docs/ci.md, "Docs site").
#
#   == Group title | Group lead (optional)   starts a sidebar group. The lead becomes the group index description.
#   ==                                          ends the group: the pages below it are top-level pages again.
#   path | Sidebar label | Description (optional)   a page; the description is used when the page has no page-description.
#
# stage.sh fails on a docs/*.md file that is not listed here, and on a listed file that does not exist, so a new,
# renamed or removed page always shows up in this file. STAGE_LENIENT=1 turns both errors into warnings.
# The landing page (README.md) is not listed: it is the home page of the site.

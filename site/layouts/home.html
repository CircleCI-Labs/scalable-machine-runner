Your first job

  1. Create a resource class and token with the CircleCI CLI (install the CLI, then circleci auth login).
  2. Follow Quickstart on Linux or Quickstart on Windows Server: download a release, verify it, deploy the stack, and run a sample workflow.
  3. Point a real workflow at your class. Start from examples/linux-hello.yml on GitHub.

Install paths, operations, and security are in the documentation.

Support

CircleCI support does not cover this repository. Field engineering handles issues on a best-effort basis, without an SLA. Open a GitHub issue for a bug or a feature request, or ask on CircleCI Discuss. Problems with the CircleCI platform or the runner agent go to CircleCI support. To report a security vulnerability, read SECURITY.md.

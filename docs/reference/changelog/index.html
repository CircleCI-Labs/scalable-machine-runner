Changelog

Machine runner swarm changelog

The release notes are on GitHub Releases. Read the notes of every release between yours and the one that you install before you upgrade: the project follows Semantic Versioning and starts at 0.x, so a minor release can contain breaking changes, which the notes list first.

A CircleCI job writes the notes of each release from the Conventional Commits on main, with the rules in cliff.toml. Nobody edits this file by hand, and the release job never commits to main. Each release bundle contains a CHANGELOG.md with the notes of every release, and you can create the same text with git cliff. Refer to Releasing for how versions and notes are made, and to Contributing for the commit types and for how to mark a breaking change.
